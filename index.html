Trouver les meilleurs dépôts GitHub, sans perdre de temps

GitHub héberge plus de 400 millions de dépôts : trouver celui qui vaut vraiment le coup peut prendre des heures. RepoFinder interroge GitHub en temps réel et classe les projets par étoiles, forks, activité récente ou selon notre score qualité maison. Filtrez par langage (Python, JavaScript, TypeScript, Rust, Go, Java…), par date de création ou par popularité, et repérez en un coup d'œil les projets 🔥 en forte croissance.

Que vous cherchiez une bibliothèque pour votre prochain projet, une alternative open source à un logiciel payant, les dernières pépites en intelligence artificielle ou un premier projet auquel contribuer, RepoFinder vous fait gagner du temps.

Questions fréquentes

Comment trouver les meilleurs repos GitHub ?

Tapez un sujet (par exemple « machine learning » ou « react ui »), choisissez un langage et un nombre minimum d'étoiles, puis triez par étoiles ou par score qualité. RepoFinder interroge GitHub en direct et classe les dépôts pour vous.

Comment est calculé le score qualité ?

Le score qualité (0 à 100) combine la popularité (étoiles), la vitesse de croissance, l'activité récente, la communauté (forks) et la documentation (description, licence, topics). Les projets archivés sont pénalisés.

Comment voir les repos GitHub en tendance cette semaine ?

Cliquez sur « Tendances de la semaine » : RepoFinder affiche les dépôts créés ces 7 derniers jours qui gagnent le plus d'étoiles.

RepoFinder est-il gratuit ?

Oui, RepoFinder est entièrement gratuit et sans inscription. Un jeton GitHub optionnel permet simplement de faire plus de recherches par minute.

Comment trouver un projet open source pour débuter ?

Utilisez le filtre « Pour débuter » : il sélectionne des projets actifs et populaires qui proposent de nombreuses issues « good first issue », idéales pour une première contribution.
